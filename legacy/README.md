# Legacy prototype snapshot

These files are the original single-file Purana Bazaar prototype, kept for reference and for the Phase 0 audit. They are not part of the build and are ignored by ESLint and Prettier.

- `Index.html` — original markup and screen order
- `script.js` — original Supabase and UI logic (credentials redacted)
- `style.css` — original styling

The Supabase project referenced by the original code no longer resolves. The URL and publishable key in this snapshot have been replaced with placeholders. The untouched originals remain in the owner's Downloads folder.

Do not copy patterns from these files into `src/`. See `AUDIT.md` for the issues found and the fixes planned by phase.
